REAK Workstation Setup

Run the command for your platform. The workstation account is reak and the SSH account is administrator; only the SSH public key and Fleet enrollment secret are required.

Ubuntu

Run from a terminal on a fresh Ubuntu amd64 desktop. You will be prompted for the administrator SSH public key and the Fleet enrollment secret. Only those two values are required; there are no skip or feature flags. Do not use sudo -E; its environment is commonly cleared by sudoers.

wget -qO /tmp/reak-setup.sh https://it.reak.co.in/workstations/ubuntu/setup.sh
sudo bash /tmp/reak-setup.sh

For a non-interactive run, enter a root shell and export the same two values:

sudo -i
export SSH_PUB_KEY="$(cat /path/to/reak-admin.pub)"
read -rsp "Fleet enrollment secret: " ENROLL_SECRET; printf '\n'; export ENROLL_SECRET
bash /tmp/reak-setup.sh

Windows

Run from PowerShell started as Administrator on a Windows x64 desktop. The defaults are reak and administrator; set only the SSH public key and Fleet enrollment secret.

$env:SSH_PUB_KEY = "YOUR_ADMIN_PUBLIC_KEY"
$env:ENROLL_SECRET = "YOUR_FLEET_ENROLL_SECRET"

Invoke-WebRequest https://it.reak.co.in/workstations/windows/setup.ps1 -OutFile setup.ps1
powershell -ExecutionPolicy Bypass -File .\setup.ps1
Download setup.ps1
