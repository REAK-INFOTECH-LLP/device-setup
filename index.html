Ubuntu Workstation Setup + Fleet Enrollment

One script: baseline hardening, apps and tooling, then automatic Fleet enrollment.

Download setup.sh Browse files

Quick install

One-line install (replace the placeholder values):

export SSH_PUB_KEY="YOUR_ADMIN_PUBLIC_KEY"
export ENROLL_SECRET="YOUR_FLEET_ENROLL_SECRET"
curl -fsSL https://reak-infotech-llp.github.io/device-setup/workstations/ubuntu/setup.sh | sudo -E bash

Full version with all variables:

export REAK_USERNAME="reak"
export REAK_SSH_USER="administrator"
export SSH_PUB_KEY="YOUR_ADMIN_PUBLIC_KEY"
export ENROLL_SECRET="YOUR_FLEET_ENROLL_SECRET"
export SKIP_FLEET="0"

curl -fsSL https://reak-infotech-llp.github.io/device-setup/workstations/ubuntu/setup.sh -o /tmp/reak-setup.sh
chmod +x /tmp/reak-setup.sh
sudo -E /tmp/reak-setup.sh

Baseline only (no Fleet secret needed): set SKIP_FLEET=1 and skip ENROLL_SECRET.

What it does

  1. Safety checks: root, Ubuntu/Debian, amd64.
  2. Creates the reak user (locked, no password).
  3. Installs baseline packages.
  4. Validates your SSH key, then hardens SSH (key-only, administrator only).
  5. Installs Docker, Chrome, Bruno, VS Code, NVM, Go, opkssh.
  6. Enrolls the host in Fleet: builds the deb with fleetctl, installs it, starts Orbit, verifies connectivity, deletes the temp package.
